# Начальный CPU baseline

Дата: 5 октября 2026. Linux/WSL2 x86_64, Python 3.12.3, SQLite 3.45.1.
GPU не использовался; модели не загружались. Метрики относятся только к маленькой
предоставленной выгрузке и не предсказывают скорость на 500 000 сообщениях.

| Метрика | Измерение |
| --- | --- |
| Сообщения | 221 |
| Непустые lexical документы (отдельные сообщения) | 208 |
| Уникальные читаемые фотографии | 10 |
| Отсутствующие вложения других типов | 4 |
| Повреждённые изображения | 0 |
| JSON | 81 867 байт |
| text строка / массив entities | 219 / 2 |
| Длина текста, символы: среднее / p50 / p95 | 15,94 / 9 / 47 |
| Полный импорт, включая fingerprint и проверку медиа | 115,09 мс |
| Повторный импорт: неизменённые сообщения | 221 из 221 |
| Размер SQLite после checkpoint | 278 528 байт |
| Warm API p50 / p95 | 5,59 / 15,09 мс |
| RSS процесса, sampled peak (интервал 10 мс) | 54,54 МиБ |

Поисковые измерения: 40 автоматически выбранных одиночных термов, 5 повторений,
200 запросов FastAPI TestClient после одного прогрева каждого запроса. Время включает
HTTP/ASGI обработку, FTS5, фильтры и сериализацию окон контекста; исключает браузер
и TCP. Реальные термы, message IDs и ручная разметка не публикуются. Измерение RSS
не включает браузер/uv и может пропустить пики короче интервала сэмплирования.

Нет измерений Recall/nDCG, cold-query, search-during-import, E5/CLIP/OCR, количества
token-budget dense chunks и tokenizer lengths. До таких измерений оценки ресурсов
из исходного плана остаются непроверенными. Windows/macOS не тестировались на
физических устройствах; добавлена CI-матрица для установки и synthetic smoke tests.

Повторение (нужен **пустой** workspace, исключённый из Git):

```sh
uv run python scripts/benchmark_lexical.py /path/to/result.json --workspace workspace/benchmark-new
```

Скрипт пишет только агрегаты в локальный `reports/lexical.json` внутри workspace.
Он не отправляет данные во внешние сервисы и не сохраняет поисковые запросы в отчёт.
