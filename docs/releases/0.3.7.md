### What's new

- Semantic search across messages, images, and OCR now reads each vector table in one streaming pass instead of repeatedly searching it for every 512 candidates.
- Dialog, author, date, content, publication, and OCR model filters still apply before selecting the best matches. Retrieval remains exact cosine search with bounded memory.
- Existing CPU/GPU embeddings and indexing progress remain compatible. Updating does not require model downloads or reindexing.
- On 65,536 generated vectors, a reproducible CPU benchmark including synthetic SQLite eligibility improved from 13.46 s to 0.40 s, with the same top 100 results. Actual archive performance depends on its size and hardware.
