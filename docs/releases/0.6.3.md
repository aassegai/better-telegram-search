### What's new

- **Set up Telegram in the app**: enter your API ID and API Hash in Sources, then sign in with your phone number, code and two-step verification password. Credentials are stored locally. Invalid codes can be retried, and expired codes can be requested again.
- **Automatic message sync** resumes selected chats after a network interruption or an ordinary app restart, using the saved session and history cursor. Telegram login remains responsive while indexing writes are in progress.
- **More useful indexing estimates** use recent successful batches, text length and padding, current batch sizes and separate CPU/GPU measurements. Remaining time appears as a range; paused, stalled or memory-blocked work no longer promises a completion time.
- **Clear RAM-limit diagnostics** show app memory use, the configured threshold and available system RAM, with a shortcut to general settings. The threshold includes the app and its OCR processes; completed indexing is preserved when you raise it and resume.
- New dialogs use advanced text chunking by default. The chunking selector has been removed; existing indexes, rules and saved progress are preserved.
