### What's new

- **Faster vector storage maintenance.** Small index files are compacted automatically, and obsolete vectors are cleaned in batches instead of scanning the store after every indexed day.
- **Responsive maintenance.** Search and settings remain available while files are compacted. The interface shows Index maintenance and hides the stale indexing ETA during the operation. Existing vectors, snapshots and indexing progress are preserved.
- **Clear noise-family choices.** Each family shows whether all, some or none of its variants are selected for omission. Changes remain visible after saving, reloading and discarding edits.
- **Simpler filter defaults.** Family variants initially select Omit with protections, except common Russian yes/no responses and their recognized variants. Manual Keep decisions take priority. The 1,000-override limit has been removed.
- **Better family grouping.** New analyses group messages that differ only in leading or trailing punctuation, such as an extra closing bracket. Every observed variant remains independently selectable.

Updating does not rebuild indexes. Continue existing indexing after the update; filter changes affect the text index only after you explicitly apply the rules. The original archive and keyword search are preserved.
