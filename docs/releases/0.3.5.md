### What's new

- PaddleOCR can now recognize different images on CPU and GPU simultaneously. Select **CPU + GPU** in OCR model settings; both workers share the existing recognition cache and pause together.
- GPU OCR groups compatible text regions into larger batches while preserving recognition order and fixed input padding. Completed recognition does not need rebuilding.
- E5 now recognizes ONNX Runtime CUDA arena allocation errors and automatically reduces its indexing batch. The reduced batch is reused across days and OCR text indexing.
- Failed text-indexing tasks show an error and a retry action instead of an active progress label and a stale completion estimate. Ready chunks remain available.
- Preparing E5 validates both indexing and search devices. Idle cleanup preserves models that are actively indexing text from images.
- CPU and GPU inference use separate resource queues; OCR diagnostics now report processing and waiting times without message or image content.
