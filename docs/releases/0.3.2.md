### What's new

- Faster CPU OCR reuses an isolated process and loaded Russian/English dictionaries across images. Per-image timeouts and automatic worker recycling are retained.
- OCR has its own visible progress card in each chat, with processed-image counts, pause status, errors, and an estimate for the remaining recognition queue.
- A separate progress bar shows semantic indexing of images with recognized text.
- OCR estimates learn from complete media-worker cycles, including time shared with CLIP and E5. Observed rates survive restarts; completed recognition is preserved.
