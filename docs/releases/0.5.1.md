### What's new

- Exclude selected authors from indexing in each chat, including their messages, images and OCR. Useful for newsletter bots. The original archive and full message context remain available.
- Changing exclusions rebuilds only affected days of the text index. Paused queues stay paused, and shared image and OCR caches are preserved.
- Search now keeps up to 100 ranked results in a short-lived memory cache. Use **Show more** to load the next page without running the models again.
- Cached pages preserve ranking and are invalidated when the archive, exclusions or search settings change. Existing models, embeddings and completed OCR remain compatible.
