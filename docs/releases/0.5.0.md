### What's new

- Optional Telegram synchronization receives new messages, edits and photos from selected cloud chats. Link an existing Desktop archive after checking the overlapping history, or start a new chat from a chosen date.
- Each chat has automatic updates, pause/resume, retry controls, photo downloads and deletion policies. Archived copies of deleted messages are marked and can be hidden from search. [Telegram connection setup](https://github.com/aassegai/better-telegram-search/blob/v0.5.0/docs/telegram-sync.en.md).
- OCR keyword search combines BM25 with literal substrings and small spelling errors. Exact word matches rank first, and every meaningful query term must match. Exact phrase mode retains literal matching.
- Keyword search skips common Russian and English stop words in messages and OCR while preserving negations. Exact phrase searches can still include stop words.
- Confirmed updates clean up obsolete installation files and downloads. Unchanged GPU libraries continue to be reused from the cache.
- Existing messages, downloaded models, CPU/GPU embeddings and completed OCR remain compatible. The OCR word index updates automatically without rerunning recognition.
