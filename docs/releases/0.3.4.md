### What's new

- Long search fragments no longer push Settings below the window. Results and the chat list scroll independently; narrow screens keep Settings in the top bar.
- Search display controls now sit beside the search filters. Opening and closing them preserves unsaved values.
- Saving result count and messages per fragment no longer waits for archive or indexing work to release the database lifecycle lock, including when reducing both values to 5.
- Slow status responses no longer accumulate overlapping background refresh requests.
