### What's new

- **Index cleanup is available while storage details load.** The Clear buttons in each chat no longer wait for vector counts and disk-size estimates. A delayed or failed estimate shows a clear message and can be retried.
- Cleanup still requires confirmation, affects only the selected chat and preserves messages, photos, recognized OCR and vectors shared with other chats.

- **Fixed a severe slowdown in filtered keyword and hybrid search.** SQLite now starts from full-text matches instead of repeating a MATCH lookup for every message in the selected chat and date range.
- **Diagnostics stay responsive during searches.** `/api/doctor` returns the live search stage and counters immediately, with detailed diagnostics collected in the background. Database integrity scans are cached instead of repeated on every request.
