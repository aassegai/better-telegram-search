### What's new

- **Filter by forward source**: find authors or channels by name and select several with checkboxes. The filter combines with author, chat, date and content filters across text, image and OCR search, including result context and cached pages. No reindexing is needed.
- Forward sources can now be filled in during repeat imports and Telegram synchronization even when the message text is unchanged. Completed vectors and indexing progress are preserved, and a missing display name never replaces a known name with an ID.
- **Shared indexing resources** now combines CPU, RAM, GPU memory and GPU load controls in one place with a single save button. Saving sends only changed settings, so live GPU load adjustments do not acquire indexing resource locks.
- Fixed the local-access error when opening or reloading the app after an update. External access to API data and embedded app pages remains blocked.
- Improved source selection on narrow screens, retry behavior, safe display of source names and English translations.
