### What's new

- Light and dark themes, a top-bar toggle, and a saved preference. The first launch follows your system theme.
- Independent E5 and CLIP indexing/search devices, plus a separate OCR device selector. Each model's settings show its download folder.
- Optional PaddleOCR for Russian/English recognition through ONNX Runtime on CPU or GPU, without Torch. Text lines use bounded microbatches with automatic reduction on memory exhaustion.
- A dedicated OCR pause/resume button, independent of CLIP image indexing. Existing Tesseract results remain available when using Tesseract; PaddleOCR keeps its own CPU/GPU-compatible cache.
- A visible search progress indicator while a query is running.
- Export sources moved from general settings to each chat's indexing menu, with file checks and folder relinking.
