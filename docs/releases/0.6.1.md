### What's new

- **Clear vector indexes separately** in Settings → Disk usage: text, images or OCR text across all chats. Cleanup waits for the current batch, shows progress and reclaimed space, and leaves the selected index paused until you resume it. Messages, photos, downloaded models and recognized OCR text are preserved.
- **GPU performance controls** add a memory limit per CUDA model and Economy, Balanced and Maximum indexing presets. The load setting uses pauses between GPU batches and takes effect immediately; interactive search keeps priority. Pause indexing before changing the memory limit. Existing embeddings remain compatible.
- Fixed CPU search waiting behind GPU cooldowns in Auto mode, and concurrent image searches reloading sessions with an outdated memory limit.
- Improved cleanup status updates, confirmation dialogs, English translations and settings layout on narrow screens.
