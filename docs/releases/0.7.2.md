### What's new

- **Faster filtered text and hybrid search.** Canonical chunk selection starts from the selected messages instead of repeatedly scanning unrelated history. Vector reads use bounds from eligible chunks while preserving all filters.
- **Faster image and OCR results.** Search no longer waits for global indexing forecasts and device diagnostics after finding matches. Coverage is calculated for the selected search area.
- **Reliable ANN fallback.** Exact retrieval reopens the complete filtered scope after a failed or unavailable ANN attempt and avoids repeated table scans when an older archive has no scalar ID index or a large unindexed tail.
- **Clearer search progress.** Separate stages show scope selection, OCR matching, vector retrieval, result assembly, coverage and reranking.

Existing databases, downloaded models and indexed progress are preserved. Reindexing is not required.
