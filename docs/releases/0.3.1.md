### What's new

- Prepare E5, CLIP, and OCR models and choose GPU/CPU devices in application settings. Manage each chat's indexing from its own menu.
- Matching text and image indexing cards with batch presets, pause/resume, and remaining-time estimates for the whole queue.
- Larger indexing batches: up to 128 texts or 32 images. Memory shortages automatically reduce batches without resetting saved progress.
- Resume existing CPU indexes on GPU, including after preparing the same model again.
- GPU updates cache libraries by SHA-256 and download only changed files. Full portable GPU packages remain available.
- Release notes render Markdown. Settings are easier to find; result count and fragment size are on the main search screen.
- Keywords and meaning is the default search mode. Import help correctly identifies the folder containing result.json.
- Fixed update rollback caused by slow database checks on large archives.
