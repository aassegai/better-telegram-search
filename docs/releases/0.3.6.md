### What's new

- Text, image, and OCR indexing show a prominent failure count beside progress and a **Retry errors (N)** button. The explanation makes it clear that failed tasks remain unprocessed and completed results are preserved.
- OCR reports recognition failures and semantic indexing failures separately. A full recognition progress bar with remaining errors explicitly requires a retry.
- Retrying errors queues failed tasks for the selected dialog without rebuilding completed indexing. Unrelated dialogs and model caches are preserved.
- Error notices and retry controls support English, Russian, the dark theme, and narrow screens.
