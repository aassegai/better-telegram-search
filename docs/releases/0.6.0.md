### What's new

- **BERTA** for semantic text/OCR search and **SigLIP 2** for image search are now recommended for new indexes. Models run locally through ONNX Runtime; PyTorch is not required in the app.
- Optional **Giga reranking** refines text and OCR results before combining search branches. It is disabled by default and prepared separately; enabling it does not rebuild the main index.
- New conversation fragments group messages by author, include nearby replies and split long messages with overlap. Each fragment allows **8 meaningful messages and 480 tokens**. Short replies and other retained context consume tokens without using a message slot; meaningful attachment captions use both.
- Whole-message filler reactions can be excluded from semantic fragments while remaining available to keyword search. Bot commands without `/` or `@` are unchanged.
- Model selection and fragment rules have explicit reindexing controls. Existing E5/CLIP indexes keep working and resume with their current models. Switching text models rebuilds text and semantic OCR; switching image models rebuilds image vectors. Messages, recognized OCR, settings and author exclusions are preserved.
- CPU/GPU indexing and search continue to use the same model space. Model downloads verify pinned checksums and reuse the local cache; unchanged GPU libraries are reused by the updater.
