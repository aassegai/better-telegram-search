### What's new

- **Noise analysis focuses on short messages.** It considers messages with fewer than five unique normalized words. Longer messages are skipped and counted, while the original archive and keyword search are preserved.
- **Limits no longer block exact rules.** Partial reports remain reviewable and allow explicit keep/omit rules, including valid partial reports created in 0.7.2. Incomplete coverage is shown honestly; new ambiguous and unexamined forms are kept automatically; previously approved exact rules remain in effect.
- **Time-limited analysis keeps its results.** Reaching the time budget finalizes the collected report instead of leaving an unusable result. Forms not yet scored remain available for manual review.

Existing databases, models and indexed progress are preserved. Installing this update does not rebuild indexes. Applying changed noise rules explicitly rebuilds only the selected dialog's text index.
