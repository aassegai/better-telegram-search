### What's new

- **Search tabs, history and favorites.** Keep independent queries open, restore your last ten searches and star searches you want to keep. Saved results reopen without rerunning model inference.
- **Browse without a query.** Select chats, authors, dates or forwarded sources and use Show messages. Browsing works without preparing a model.
- **Search progress and Stop.** Follow the current stage and cancel a slow query. Show more continues through the saved result set.
- **Faster vector search with optional ANN.** Choose exact or approximate search, manage background ANN indexing and inspect the effective strategy in diagnostics. Chat and message filters still apply.
- **Text noise analysis per chat.** Review repeated reactions and typo variants, compare their effect on chunks and apply explicit rules. Original messages and keyword search are preserved. Ambiguous new forms stay unless you choose to exclude them.
- **More built-in model choices.** UltraBERT is available for English semantic retrieval and Jina v2 for optional reranking alongside BERTA and Giga. Language buttons change the interface and recommendations; they do not switch your models. Jina v2 is licensed for noncommercial use under CC-BY-NC-4.0.
- **Clearer settings and import progress.** Model cards and performance controls share a consistent layout, and export checking shows progress before the import starts. Windows export inspection no longer confuses file identifiers returned by different system APIs.
- **More resilient indexing.** Temporary SQLite locks no longer kill the text-indexing worker. Worker health and safe error diagnostics help distinguish waiting, failures and active work. Vector cleanup remains scoped to the selected chat.
- An English quickstart is now the main README, with a complete Russian version alongside it.

Pause indexing before updating. Archives, completed indexes, recognized OCR, models and settings are preserved. Existing indexes remain usable; choosing a different text or image encoder requires explicit reindexing.
