# Автоматическое обслуживание векторных файлов

Приложение проверяет статистику файлов при старте, затем не чаще раза в минуту
или после 64 записей. При накоплении 128 мелких фрагментов оно уплотняет одну
активную таблицу и возвращается к индексации. Обслуживаются текстовые векторы,
смысловой OCR и изображения. Пересчёт эмбеддингов и загрузка моделей не требуются.

Уплотнение выполняет CPU-процесс: до четырёх потоков, половина лимита RAM
приложения, максимум 2 ГиБ и 120 секунд. Неудачная попытка откладывается на пять
минут и не ставит индексацию на паузу. Поиск остаётся доступен; публикация новых
векторов ждёт без удержания общей блокировки приложения. При выходе процесс
обслуживания останавливается до освобождения блокировки workspace.

Физическое удаление устаревших векторов после каждого дня заменено постоянной
очередью. За одну проверку пространства обрабатывается до 64 дней. Очередь
сбрасывается при накоплении 32 дней, через 60 секунд либо при простое/паузе.
Поколения SQLite сразу исключают старые векторы из поиска. Подтверждение очистки
проверяет диалог, день, пространство и поколение; после сбоя запрос повторяется.

Автоматический режим сохраняет версии за семь дней и не удаляет новые файлы
незавершённых транзакций. Дополнительная временная метка закрепляет версию для
текущих читателей, даже если эта версия старше семи дней. Она снимается после
остановки процесса и завершения читателей; пользовательские метки сохраняются.
Если Lance уже завершил уплотнение, но отказался удалять закреплённые версии,
подтверждённое уплотнение принимается, а удаление истории откладывается. Прочие
ошибки не выдаются за успех.

Во время операции интерфейс показывает **Уплотнение индекса** и скрывает прежнюю
оценку времени. Состояние `vector_maintenance` также доступно в worker health
через `/api/indexing/health` и `/api/doctor`. Готовые векторы и прогресс сохраняются.

## Синтетический CPU-замер

```sh
uv run --extra semantic python scripts/benchmark_vector_maintenance.py
```

Скрипт создаёт и удаляет отдельную временную базу, не открывает приложение,
переписки, модели и GPU. Проверяет значения векторов, ID и реальное чтение снимка,
открытого до уплотнения.

[Замер в Windows](benchmarks/vector-maintenance-synthetic-windows.json): 256 файлов
объединились в один. 32 отдельных проверки заняли 0,655 с, пакетная — 0,035 с,
после уплотнения — 0,0073 с. Само обслуживание заняло 4,91 с. Это замер хранилища
на синтетических данных, не обещание такого же ускорения полной индексации.
