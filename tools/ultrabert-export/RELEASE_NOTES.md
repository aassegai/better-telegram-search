### What's new

- Verified ONNX bundle for UltraBERT-Embed-150M, the English text retrieval model.
- FP16 matrix storage with FP32 computation and CLS/L2 pooling. The application
  runs inference through ONNX Runtime without PyTorch or remote model Python.
- Pinned source revision, graph checksum and native-reference CPU parity report.

These are model assets downloaded by the application, not an application update.
Upstream model: https://huggingface.co/dmis-lab/UltraBERT-Embed-150M (Apache-2.0).
