# Better Telegram Search

[English](README.md) · Русский

Поиск по архиву Telegram: слова, смысл, описание картинки и текст на изображениях.
Помогает найти нужное сообщение, даже если вы не помните точную формулировку,
и открыть его вместе с окружающим разговором.

Приложение работает локально и открывается в браузере. Встроенные модели обрабатывают сообщения
на вашем компьютере через ONNX Runtime; переписка не отправляется во внешний
AI-сервис.

## Возможности

- Поиск по тексту, картинкам и OCR с фильтрами диалога, автора, дат и источника пересылки.
- Просмотр сообщений по фильтрам без запроса и подготовки моделей.
- Фрагменты переписки, переход к контексту и просмотр картинок внутри страницы.
- Независимые вкладки, история последних десяти поисков и избранное.
- Исключение отправителей из индексов диалога и предпросмотр правил текстового шума.
- Новые сообщения и фотографии выбранных диалогов через необязательное подключение Telegram.

## Quickstart

1. Скачайте архив для своей ОС и архитектуры из [GitHub Releases](https://github.com/aassegai/better-telegram-search/releases/latest).
   Выберите обычную CPU-сборку либо полный пакет `-gpu` для NVIDIA на Windows/Linux x64.
2. Полностью распакуйте архив и запустите приложение:

   | Платформа | Запуск |
   | --- | --- |
   | Windows x64 | `BetterTelegramSearch/telegram-search.exe` |
   | Linux x64 / ARM64 | `BetterTelegramSearch/telegram-search` |
   | macOS Intel / Apple Silicon | `Better Telegram Search.app` |

   Устанавливать Python и Node.js для готовой сборки не нужно. Браузер откроет
   `http://127.0.0.1:8765`. Язык **RU / EN** и тема переключаются вверху страницы.
3. Экспортируйте один диалог из Telegram Desktop в формате **JSON**, при необходимости
   включив фотографии. Нажмите **«Импорт сообщений»**, укажите `result.json`, проверьте
   выгрузку и примените изменения. Необязательная папка выгрузки — **родительская папка,
   содержащая `result.json`**. Сохраняйте её: импортированные фотографии остаются там.
4. Введите запрос и нажмите **«Найти»**. Поиск по словам доступен после импорта.
   Для просмотра без запроса задайте фильтры и нажмите **«Показать сообщения»**.
5. Для смыслового поиска, картинок или OCR откройте **«Настройки → Модели»**, выберите
   и подготовьте нужную модель. В меню **⋯** диалога виден прогресс; там же можно
   продолжить приостановленный этап. Первая подготовка скачивает файлы моделей,
   затем поиск работает без сети.

Можно начать с **«Источники · Telegram»**: войти в аккаунт и связать выбранный
Telegram-диалог с локальным архивом. Перед подтверждением проверьте совпадение
истории. [Инструкция подключения](docs/telegram-sync.md) описывает API-реквизиты,
хранение сессии и ограничения синхронизации.

## Поиск и индексация

**«Слова и смысл»** объединяет лексический и смысловой поиск. Выберите **«По словам»**
для поиска значимых слов запроса или **«Точная фраза»** для буквального совпадения.
Обычный поиск по словам пропускает служебные RU/EN слова и сохраняет отрицания.
В OCR также поддерживаются подстроки и небольшие опечатки. В **«Искать в»** можно
сочетать **текст**, **изображения** и **OCR**.

Настройки выдачи задают число результатов на странице и сообщений в отображаемом
фрагменте. **«Показать ещё»** открывает следующую часть сохранённой выдачи,
**«Открыть контекст»** — соседние сообщения. История и избранное с жёлтой звездой
восстанавливают параметры и результаты; вкладки сохраняют независимые фильтры
и выдачу. **«Остановить»** отменяет текущий поиск; следующий запускается с начала.

Для новых текстовых индексов рекомендуется BERTA для русского и UltraBERT для
английского; картинки ищет SigLIP 2. Необязательные Giga/Jina уточняют порядок
текстовых/OCR результатов. Смена языка не переключает модель. Смена текстовой или
визуальной модели требует явной переиндексации; сообщения и распознанный OCR
сохраняются. Прежние индексы продолжают работать.
[Подробнее о моделях и переходе](docs/model-migration.md).

В **«Настройки → Производительность»** собраны устройства, память, батчи и
переопределения для диалогов. Можно индексировать на GPU, а искать на CPU в той же
базе: смена устройства сохраняет готовую работу. Для NVIDIA нужны совместимый
драйвер и GPU-сборка; отдельно устанавливать Torch не требуется.
[Устройства и обновления](docs/gpu-and-updates.md).

## Запуск из исходников

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Node.js 22+.
uv создаст отдельное окружение `.venv` и при необходимости установит Python 3.12.

```sh
git clone https://github.com/aassegai/better-telegram-search.git
cd better-telegram-search
uv sync --locked --python 3.12 --extra semantic --extra ocr --extra telegram
npm ci --prefix frontend
npm run build --prefix frontend
uv run --no-sync telegram-search run
```

Для следующих запусков достаточно последней команды. Данные исходной версии
хранятся в `workspace/`, готовых сборок — в пользовательском каталоге ОС.
Отдельное GPU-окружение и требования сборок описаны в руководствах ниже.
